Responsive Breakpoints

All utility classes support responsive prefixes. Add a breakpoint prefix to apply a utility at a specific screen width and above.

Prefix Min Width Example Description
(none) 0px .d-flex Base (mobile first)
sm: 576px .d-sm-flex Small screens (landscape phones)
md: 768px .d-md-flex Medium screens (tablets)
lg: 992px .d-lg-flex Large screens (desktops)
xl: 1200px .d-xl-flex Extra large screens
2xl: 1400px .d-2xl-flex Ultra wide screens
HTML 
<!-- Hidden on mobile, visible on md+ -->
<div class="zak-d-none zak-d-md-block">
  Only visible on tablets and up
</div>

<!-- Responsive grid: 1 col on mobile, 2 on md, 3 on lg -->
<div class="zak-grid zak-grid-cols-1 zak-grid-cols-md-2 zak-grid-cols-lg-3 zak-gap-4">
  <div>Card 1</div>
  <div>Card 2</div>
  <div>Card 3</div>
</div>

<!-- Responsive text alignment -->
<p class="zak-text-center zak-text-md-start">
  Centered on mobile, left-aligned on desktop
</p>
